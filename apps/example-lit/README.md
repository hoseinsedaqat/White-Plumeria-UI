# Studio desk

A small invoice desk built with `@white-plumeria/lit`. The records are sample workspace data. Filtering, voiding, theme changes, and saving stay in this browser tab. Nothing is sent to a server.

```bash
pnpm --filter @white-plumeria/example-lit dev
```

The dev server listens on `0.0.0.0:5181`. It renders in the browser. SSR is not part of this example.
